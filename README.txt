MULTIGESTIÓN MR — V1.0
Sistema Multinegocio de Gestión Financiera y Operativa

FUNCIONES DE ESTA VERSIÓN
- Crear múltiples negocios o proyectos.
- Seleccionar cada negocio de forma independiente.
- Registrar gastos, compras, ingresos y ventas.
- Fecha, categoría, producto/concepto, cantidad, unidad, precio unitario, total, proveedor/cliente, forma de pago y observaciones.
- Totales generales y por negocio.
- Historial y filtros.
- Base de datos local IndexedDB en el dispositivo/navegador.
- Exportación individual de cada negocio a Excel .xlsx cuando la librería XLSX está disponible.
- Respaldo CSV compatible con Excel si la librería no carga.
- Instalación como PWA en navegadores compatibles.

IMPORTANTE
La información se guarda en el navegador/dispositivo donde se utiliza la aplicación. En una siguiente versión se puede añadir respaldo/importación de base de datos, inventario, caja, cuentas por cobrar/pagar, ciclos agrícolas, producción y sincronización en nube.

PARA PROBAR
Publique la carpeta en un servidor HTTPS (por ejemplo GitHub Pages) para usar IndexedDB, PWA e instalación con mayor compatibilidad. También puede abrir index.html directamente, aunque algunas funciones PWA requieren HTTPS.
